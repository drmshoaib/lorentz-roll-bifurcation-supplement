# Reproducibility notes and model boundaries

The accompanying *Acta Astronautica* manuscript retains the derivation and the three-axis validation. This public release provides independent access to numerical sources and supporting data. The scripts use the original directory layout so their relative imports and data lookups remain unchanged.

## Source-to-result correspondence

| Question or quantity | Computational source | Stored output |
| --- | --- | --- |
| Reference fold and fitted critical exponents | `revision_checks/independent_fold_check.py`; `revision_checks/scientific_audit.py` | `revision_checks/results/scientific_audit.json` |
| 32-orbit constrained-roll sensitivity to the initial angle | `revision_checks/orbital_poincare.py` | `orbital_ensemble_members.csv`, `orbital_ensemble_summary.csv` |
| Matched orbitally forced trajectories and stroboscopic section | `revision_checks/orbital_poincare.py` | `orbital_matched_summary.csv`, `orbital_stroboscopic_points.csv` |
| One-orbit periodic shooting and monodromy matrix | `revision_checks/orbital_poincare.py`; `revision_checks/scientific_audit.py` | `orbital_periodic_branch.csv`, `orbital_floquet_finite_difference.csv` |
| Three-axis tracking and tolerance convergence | `revision_checks/controlled_three_axis_validation.py`, `revision_checks/validation_tables.py` | `revision_checks/three_axis_results.csv`, `results/three_axis_tolerance.csv` |

| IGRF-14 spectral results | `manuscript_figure_scripts/figures/generate_igrf_spectrum.py` | Figures regenerated under `figures_out/` |

Unless a path is absolute, the output names in this table are relative to `research_assets/python/revision_checks/results/`.

The original reference roll angle is **347.262167 degrees** and is applied identically to every matched orbital charge case. The source explicitly records the angle and contains a 21-point grid of offsets in [-0.01,0.01] degrees, supplemented with offsets of ±1e-6 degrees.

The 32-orbit spread is highly sensitive, and exact final spans may depend on numerical environment, rounding and initial angle. The reported ranges are finite **sample ranges**, not probabilistic confidence intervals or converged asymptotic estimates. The onset of circulation is defined by the first time the running unwrapped excursion exceeds 360 degrees.

The one-orbit response is obtained by solving a stroboscopic return condition with a separate initial state. Its monodromy trace is checked against direct finite differences. The reported ellipticity is a *linear* property and does not prove nonlinear stability.

The constrained-roll model fixes the transverse kinematics. The source `controlled_three_axis_validation.py` checks exact controlled consistency and three-orbit response to transverse perturbations in the full Newton–Euler/quaternion model. The main manuscript contains those results; public access to the code does not change that editorial decision.

The positive and negative charging scenarios are conditional current–voltage **screening calculations**, not a self-consistent sheath model or actuator design. A sphere with a 1 m effective radius is far from the attractive-electron OML small-body regime for the quoted plasma.

The IGRF data files originate from the IAGA V-MOD/NOAA release. The original coefficients are retained alongside the extracted epoch-2025 subset so users can check all 195 coefficients directly.

## Output files intentionally not versioned

Dense 32-orbit state arrays (`orbital_matched_trajectories.npz`) and three-axis trajectories (`three_axis_trajectories.npz`) are regenerated by the full runner. All nine revised manuscript figures and the supplementary figure PDFs are also generated, avoiding a second set of versioned artwork in this repository.
